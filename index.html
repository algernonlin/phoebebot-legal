歡迎使用菲比團子

菲比團子（以下簡稱「本機器人」）是一個基於 Discord 平台的非官方粉絲創作工具，靈感來自遊戲《鳴潮》角色菲比（Phoebe）。使用本機器人即表示您同意以下服務條款。

使用資格

您必須遵守 Discord 的服務條款與使用指南，方可使用本機器人。使用本服務即代表您同意相關規定，並承擔因違規使用所產生的一切責任。

服務範圍

本機器人為免費的非商業個人專案，提供以下服務：

・基於《鳴潮》主題的互動功能

・伺服器娛樂與管理輔助工具

・其他Discord相關互動功能

免責聲明

本機器人為愛好者自製作品，與庫洛游戲（KURO GAMES）及《鳴潮》官方並無任何關聯。本服務以「現狀」提供，不保證持續可用性。開發者保留隨時修改、暫停或終止服務的權利，恕不另行通知。

第三方服務
本機器人使用 Anthropic Claude AI 作為部分功能的技術基礎。使用本服務即表示您同時受 Anthropic 之 服務條款 約束。

禁止行為

使用者不得以任何方式濫用本服務，包括但不限於：惡意刷量、傳播不當內容、嘗試破解或干擾機器人運作，或用於任何違法用途。

條款變更

開發者保留隨時更新本條款的權利。重大變更將於 Discord 伺服器公告。繼續使用本服務視同接受最新條款。

菲比團子盡量以最少的資料完成服務。本政策說明我們如何處理與您互動時所產生的資訊。

收集的資訊

用於識別互動來源
訊息內容
僅限指令處理期間

資料使用方式

所收集的資訊僅用於：

・處理您的指令與請求

・維持服務的正常運作

・改善機器人功能體驗

資料儲存與安全

本機器人不會長期儲存個人對話內容。互動資料僅在處理請求時暫時存在，處理完畢後即不保留。我們不會將您的個人資料販售、出租或提供給任何第三方。

您有權要求刪除與您相關的任何資料。如有任何隱私問題，歡迎透過 GitHub 專案頁面聯絡開發者。

本隱私權政策可能隨時修訂，修訂後的版本將發布於本頁面，並更新「最後更新」日期。
